# Item bank BII

Gli item sono semplici file CSV: si possono leggere e modificare con Excel,
LibreOffice Calc o un editor di testo. Ogni riga è un item; le colonne sono
descritte in [ITEM_SCHEMA.md](ITEM_SCHEMA.md).

Lo stato corrente è intenzionalmente piccolo: `SP.csv` è un prototipo da
revisionare, non il set completo di 18 item. Prima di aggiungere molti item a
un subtest, rivedere le famiglie, la chiarezza delle consegne e la progressione
di difficoltà.

Non cambiare mai un `item_id` già usato. Se un item non va più bene, marcarlo
come ritirato o sostituirlo con un nuovo ID.
